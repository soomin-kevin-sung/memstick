# Memstick POC 1

This Tauri POC explores a Typora-like Markdown editor where source editing and
rendered preview happen in the same writing surface.

The current design rules are captured in
[`docs/editor-interaction-rules.md`](docs/editor-interaction-rules.md).

## Development

```powershell
pnpm install
pnpm dev
pnpm tauri dev
```
